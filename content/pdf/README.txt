Put PDFs for the Study library in this folder, then upload the folder to GitHub with the app.

Example: save "roadmap.pdf" here, then in the app go to Admin > Library > Add PDF and type
    content/pdf/roadmap.pdf
as the file link, tap "Test link", then Save.

Tips
- Keep each file under about 25 MB so it opens fast on mobile data.
- Use plain file names without spaces (roadmap.pdf, anatomy-notes.pdf).
- Anyone who knows a file's direct link can open it, so do not put anything here that must stay private.
